## C. 歌庫與影片

- [ ] 匯入資料可用 `歌曲 ID` 冪等更新。
- [ ] Kala 與演唱影片可分別查看；原始標題與 URL 不丟失。
- [ ] 主分類只能單選六類，三個次標籤可自由複選。
- [ ] 新歌預設可上場，管理員可手動關閉。
- [ ] 相同歌曲多次點歌保留所有提交並更新合併統計。

## D. 歌單與場次

- [ ] 正常資料下生成 12 首：台文 2、英文 2、中國歌 2、專題 5、機動 1。
- [ ] 專題可選老歌或指定歌手，且總數不變。
- [ ] 至少一首炫技歌曲可與其他名額重疊。
- [ ] 不選不可上場歌曲，並排除最近三場已演歌曲；首批兩場可部分重複。
- [ ] 首次生成兩場，後續一次只新增一場。
- [ ] 分類不足時顯示缺口，不自動改用別類補滿。
- [ ] 人工拖曳、替換與刪除後即時重算警告。
- [ ] 違反規則可在確認警告後發布，並留下稽核事件。
- [ ] 場次只由管理員手動切換；切換後上一場與下一場顯示正確。

## E. 管理、通知與資料治理

- [ ] 非白名單 Google 帳號無法查看或呼叫管理 API。
- [ ] 新互動同時出現在管理端並寄送 Email 提醒 Max。
- [ ] 歌曲排入時只通知有聯絡方式、同意回覆且尚未成功通知的點歌者。
- [ ] Email 失敗可安全重試；IG 人工待辦不得被標示為已自動送達。
- [ ] CSV 匯出、單筆刪除、批次匿名化皆受授權並記錄稽核。
- [ ] 公開頁、log、分析事件、快取及錯誤訊息不洩漏 Email、IG 或互動內容。
- [ ] 資料預設永久保留；僅管理端可刪除，匿名化後一般 UI 不可還原個資。
