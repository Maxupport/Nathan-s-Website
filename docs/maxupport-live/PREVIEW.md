# 第二階段 Demo 操作與驗證

## 目前可操作

- `/live`：六入口自適應首屏、上一場與下一場、互動表單；主題入口直接帶入表單並保存到管理收件匣及 CSV。訂閱保留為次要入口。
- 首屏提醒建議橫向使用；直向採兩欄三列、橫向及桌面採三欄兩列，以 `100svh` 分配可視高度，放大字體時保留自然捲動。
- `/live/admin`：歌庫搜尋／分類／標籤／可上場、新增示例歌曲、收件匣、狀態調整、CSV 匯出、單筆刪除與批次匿名化。
- 歌單：首次兩份不同草稿、後續一次新增一份、固定配置抽選、老歌／指定歌手模式、炫技重疊、最近三場排除、缺口提示、拖曳與上下按鈕排序、人工增刪、警告後發布與手動完成場次。
- 發布時保留歌曲快照與警告；回到觀眾頁可立即看到預告。排入點歌的通知只有狀態示例，未實際寄送。

## Demo 邊界

- 34 首示例歌曲與分類獨立於 Google Sheet，不讀取、不覆寫 Max 正在分類的資料。
- 所有變更只在目前分頁記憶體。請用頁內連結切換公開／管理頁；重新整理、另開分頁或關閉分頁會回到初始狀態。
- 請使用測試聯絡資料。無 API、無外部資料寫入、無 Email 寄送、無正式訂閱。
- 此版本無管理端 Google 登入；Preview 沿用既有 Vercel 存取保護。正式帳號白名單尚待資料層階段實作。
- Vercel 的 `production` 環境對 `/live` 與所有子路由回傳 404；只有本機／Preview 可用。解除保護、串接真實服務與 Production 部署是後續里程碑。
- 所有新增 CSS 限定於 LIVE 路由的 `.max-live` 元素內；既有全站 layout、選單與服務／部落格程式未更動。

## 建議操作順序

1. 在公開頁選「點歌」，同意本次回覆，填入測試歌名與演唱者。
2. 使用頂端「管理端 Demo」連結，至收件匣查看。
3. 在歌庫修改歌曲狀態，再回歌單重新抽選，查看配置提醒。
4. 填寫日期、時間、地點與預告文案，發布；有警告時需再次確認。
5. 以「觀眾頁 Preview」連結查看完整預告與歌單。
6. 返回管理端完成演出，手動切換上一場，再發布下一份草稿。
