# Preview 操作與驗證

最新操作方式及正式入口見 [管理操作手冊](./OPERATOR_GUIDE.md)。功能分支已啟用本人 Google 登入與同一份私人 Sheet 的收件、歌庫及場次保存；沒有設定環境變數的本機才使用獨立 Demo。

## 目前可操作

- `/live`：六入口自適應首屏、上一場與下一場、互動表單；主題入口直接帶入表單並保存到管理收件匣及 CSV。訂閱保留為次要入口。
- 首屏提醒建議橫向使用；直向採兩欄三列、橫向及桌面採三欄兩列，以 `100svh` 分配可視高度，放大字體時保留自然捲動。
- `/live/admin`：歌庫搜尋／分類／標籤／可上場、新增示例歌曲、收件匣、狀態調整、CSV 匯出、單筆刪除與批次匿名化。
- 歌單：首次兩份不同草稿、後續一次新增一份、固定配置抽選、老歌／指定歌手模式、炫技重疊、最近三場排除、缺口提示、拖曳與上下按鈕排序、人工增刪、警告後發布與手動完成場次。
- 發布時保留歌曲快照與警告；回到觀眾頁可立即看到預告。排入點歌的通知只有狀態示例，未實際寄送。

## Demo 邊界

- 未設定串接的本機使用 34 首獨立示例歌曲。已啟用的 Preview 讀取真實歌庫，保留尚未填寫的分類，不自行分類。
- 已啟用的 Preview 管理端需按「儲存修改」保存，重新整理可讀回。未設定串接的 Demo 仍只保留在目前分頁記憶體。
- 功能分支 Preview 已設定 Google Sheet 收件。新版表單收到保存回執才顯示成功，送出內容與操作事件會保留在擁有者私人試算表。未設定環境變數的本機仍為純 Demo。請使用明確標示的測試資料；目前無 Email 寄送或正式訂閱。
- 已新增本人 Google 登入及受保護的私人管理 API；Preview 另保留既有 Vercel 存取保護。
- Production 預設不開放 LIVE；經授權的正式部署需 `LIVE_RELEASE_ENABLED=true`，功能分支 Preview 保留既有存取保護。
- 所有新增 CSS 限定於 LIVE 路由的 `.max-live` 元素內；既有全站 layout、選單與服務／部落格程式未更動。

## 建議操作順序

1. 在公開頁選「點歌」，同意本次回覆，填入測試歌名與演唱者。
2. 由頂端管理端連結，以本人 Google 帳號登入，即可查看原始互動；也可使用原本私人 Google Sheet。
3. 在歌庫修改歌曲狀態，再回歌單重新抽選，查看配置提醒。
4. 填寫日期、時間、地點與預告文案，發布；有警告時需再次確認。
5. 以「觀眾頁 Preview」連結查看完整預告與歌單。
6. 返回管理端按「開始本場演出」，公開頁會優先顯示本場完整歌單；可同時發布下一份草稿。演出完成後再次確認，才移入上一場。
